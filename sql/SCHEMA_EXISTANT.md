# Schéma Supabase utilisé

Cette version utilise le schéma déjà présent dans le projet Noor Communication. Les migrations distantes ont été appliquées directement au projet connecté le 6 novembre 2026.

Tables principales : `services`, `projects`, `service_pricing`, `site_content`, `blog_posts`, `contact_messages`, `site_settings`, `noor_admin_users`.

Ne pas appliquer de migration issue d'une ancienne archive du prototype `noor_*` : elle n'est pas compatible avec le schéma courant.
